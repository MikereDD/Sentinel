# Sentinel identity

Canonical family direction established 2026-08-31.

- `Sentinel-Android.png` — clean cyan/graphite core treatment; primary Sentinel identity.
- `Sentinel-Agent-Windows.png` — cooler blue-steel desktop treatment.
- `Sentinel-Agent-Linux.png` — darker industrial treatment with restrained amber accents.

All variants preserve the same visual language: a central radar/observer surrounded by a six-node network frame.
The Android launcher uses a simplified vector derivative for adaptive/themed-icon legibility at small sizes, while the full-detail Android artwork is also used in the About screen.
